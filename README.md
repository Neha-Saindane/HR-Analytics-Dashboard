# HR-Analytics-Dashboard
This project demonstrates an end-to-end data cleaning, transformation, analysis, and dashboard development workflow using Microsoft Power BI. The goal is to transform raw data into meaningful business insights through Power Query, DAX, interactive visualizations, and KPI analysis.

## Project Overview

The project covers the complete Power BI workflow, from importing and cleaning raw datasets to building an interactive dashboard and extracting actionable insights.

### Key Areas Covered

* **Power BI Dashboard Setup** – Created and configured a Power BI report for data analysis and visualization.
* **Data Import** – Imported raw datasets from external sources into Power BI.
* **Power Query** – Cleaned and transformed data by handling missing values, duplicates, data types, formatting, and unnecessary columns.
* **Data Transformation** – Prepared datasets for analysis by filtering, merging, appending, and restructuring data.
* **DAX** – Created DAX formulas for advanced calculations and analytical metrics.
* **Measures & Calculations** – Developed calculated measures to track KPIs, performance metrics, totals, averages, percentages, and trends.
* **Charts & Visualizations** – Designed interactive charts and visuals to communicate key findings effectively.
* **Filters & Slicers** – Added interactive filters and slicers to allow users to explore data dynamically.
* **Interactive Dashboard** – Built a user-friendly dashboard combining KPIs, charts, tables, and performance indicators.
* **Dashboard Export** – Exported and shared Power BI dashboard/report outputs for business reporting.
* **Business Insights** – Analyzed dashboard results to identify trends, patterns, performance gaps, and actionable insights.
